# 目标与验收矩阵

用户经营成都银杏乒乓球俱乐部，已要求自主推进现有AI获客软件直到真正跑通。目标不是仅扫描、存草稿或让微信客服回答已有用户，而是把外部明确需求转成可核实的新报名。核心平台为抖音、快手、小红书、微信视频号；哔哩哔哩与百度贴吧次要。

| 阶段 | 必须证明 | 当前缺口 |
|---|---|---|
| 外部搜索 | 实际登录环境可操作搜索、近期筛选、准确关键词，保存平台/日期/链接 | 助手1.4.9实际Chrome重载和连续轮次未验收 |
| 公开原文与评论 | 唯一原帖、作者、正文、评论范围与发布时间，不猜作品ID | 抖音已有手工证据；快手分享链接/评论范围未完整通过；小红书设备登录超限；视频号浏览器未适配 |
| 地域与意图 | 明确成都及近期需求；非招聘招生、工作人员回复、观赛旧内容 | 新分类在1.4.5/本机，正式旧1.4.1仍有误判 |
| 去重入库 | 同帖别名/重复批次幂等，已联系/停止状态保留 | 同数字video/note已在待装包；未知来源query和小红书别名等新6例待修 |
| AI回复 | 基于原需求及有效赛事/课表，额度/错误/人工接管正常 | 有代码及微信客服；新外部线索端到端实际AI回复仍待核对 |
| 平台实际发送 | 原平台准确账号与正文可见，可靠来源回执，不只是点击 | 自动发送仍未接通；有1次人工抖音评论刷新可见，回执待补 |
| 小程序承接 | 同平台银杏奖牌比赛/训练入口实际可达，内容正确 | 各平台真实跳转仍待逐一验证；小程序客服凭据不能代替内容账号权限 |
| 真实报名与结果 | 真实报名凭证与发布凭证分开，不能把访问/咨询当报名 | 无已核实外部新客户报名证据 |
| 部署与恢复 | 实际运行hash=已测包，备份/回滚、重启状态、原微信客服均正常 | 新获客合并包待完成，不能装旧包冒充新修复 |

各平台都要填上述全链路，验证码或权限待授权不能记通过。保存失败原因和下一步即可；没有新线索也继续独立修复软件。开发定时轮次与旧“连续3个空轮暂停”的扫描规则要分清。

已授权使用正常登录账号进行明确需求的俱乐部业务回应，但不群发、不骚扰、不重复联系；平台/工具明确阻止的路径不能换通道绕过。原沟通应透明使用银杏工作人员身份，同平台完成报名承接。
