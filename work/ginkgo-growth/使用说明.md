# 银杏获客工作台 1.0

目的是把成都明确的乒乓球训练、参赛与约球需求，接到俱乐部的实际报名流程中。第一版是可运行的辅助获客系统：渠道搜索任务、需求核实、去重、回复草稿、人工联系登记、自愿咨询、报名凭据登记、渠道统计及备份。

「内容获客」另提供四个平台各七天的选题、拍摄建议和俱乐部公告草稿，尚未代为拍摄或发布。素材应真实、取得出镜许可，并在发布当天核对课表与比赛状态。

## 当前接入状态

四个平台的小程序已经存在，但**小程序 AppID/Secret 不等于社交账号评论、私信权限**。本版未把登录浏览器视为开放接口授权，没有全站评论爬虫，没有自动私信发送器，也不宣称已经获得客户。

已提供抖音、快手、小红书、视频号六十条搜索任务；另含哔哩哔哩、百度贴吧两个补充渠道。视频号的全站搜索需在微信手机端进行。搜索链接可能随平台改版变化，登录、验证码或平台限制须在平台正常处理。

## 立即使用

1. 双击「启动银杏获客.cmd」。本机版只监听 127.0.0.1:8796，桌面入口带临时本机令牌，不公开到外网。
2. 「寻找打球的人」打开搜索。核对原文、需求时间及成都证据，然后「记录一条需求」。不要把搜索关键词、IP属地或点赞当作居住地与购买意图。
3. 在「需求与跟进」查看分类与原因，确认后准备回复。草稿明确说自己是银杏乒乓工作人员，不冒充普通球友。
4. 在原帖回应具体问题，或在自己收到咨询的原会话回应。复制草稿不会记作已发出。真实发送后，填写发送账号、实际内容和原帖凭据，登记人工联系。
5. 对方回复后更新状态，再发送相应平台的「银杏奖牌」小程序卡片。比赛看「比赛」，训练看「训练」。公开回复不放微信号、电话或站外二维码。
6. 「已核实报名」必须填写实际报名记录编号。它是人工核对登记，尚未与订单自动匹配；咨询、访问和点击都不计为报名。
7. 对方拒绝后点「不再联系」，同平台相同称呼或来源的后续需求会被抑制，不会自动改回待联系。同名可能并非同一个人，系统采用保守抑制，不做跨平台身份合并。

原文发布时间不明、超过30天、不明确成都、不属于服务需求、招聘招生或观看职业比赛门票等内容，不进入待回应队列。公开评论里的手机号和常见社交联系方式在保存前隐藏。

## 浏览器记录助手（可选）

`browser-helper` 是开源的 Chrome/Edge 扩展目录，可在扩展管理页以开发者模式加载解压目录。只在用户点击时读取当前选中文字与链接。没有 Cookie 权限，没有背景任务，也不会代发消息。选中一条求助后点助手，补齐时间及成都证据，再决定保存。

无需安装扩展也可以直接复制原文到工作台。批量 JSON 导入只用于自己经营账号收到的咨询，每次最多50条；每条必须含平台、来源原文与需求内容。

## 与现有俱乐部系统的连接

比赛目录只读现有公开接口，只推荐仍开放报名、尚未开赛的成都银杏球馆赛事；同步失败或超过10分钟不继续使用旧场次。训练不编造价格、课表或剩余名额，指引小程序实时课程。

云端版挂载到现有服务的 `/api/match-center/growth/`，复用原管理员会话。使用既有姓名、手机号与密码通过原登录接口验证；不新增会员账号，不保存密码，仅俱乐部管理员可读客户资料。

客户记录存于 `growth-data/acquisition.sqlite3`，与现有 SQL 账号、赛事、积分、奖牌完全分开。数据库包含最低限度的咨询资料；不可把 SQLite 文件目录当作公开静态文件服务。工作台能创建一致性备份，勿把有客户信息的数据库公开分享。

安装器 1.0.1 已修复首次安装的数据目录权限：只给现有服务身份 `LocalService` 对专用 `growth-data` 目录的修改权限，父代码目录仍只读。重启前校验依赖与隔离导入，失败记录已脱敏的实际启动异常并还原原程序。无需下载服务器依赖。

## 报名承接页

四个主平台各有比赛和训练两类咨询入口。云端部署后可供客户自愿提交咨询。提交前明确说明联系用途，未成年人由监护人提交；咨询不等于报名。

本机地址不能从手机外网访问，不能投放。云端 H5 链接仅用在平台允许的场景，优先使用各平台既有站内小程序卡片。当前没有追踪微信小程序来源参数，所以工作台不声称自动获知客户完成付款或报名。

## 真正全自动化所缺的接入

- 抖音：官方「关键词视频管理」能力须申请，关键词要求与自有品牌相关，不能把“成都乒乓球”这种通用品类词当成已获批词；评论管理和回复还需要对应 scope。
- 快手：需核实账号实际开放能力、授权主体和消息使用范围；代发要显示账号、接收对象及最终内容。
- 小红书：优先官方专业号的咨询与获客工具，以及站内小程序承接。不能把普通网页账号登录或非官方逆向接口当成开放权限。
- 视频号：当前仅提供正常工作台和微信内搜索指引，没有已核实的全站评论采集接口。

没有连接器时，发送接口明确返回“未发送”，不会凭空把任务改成成功。平台授权尚未取得之前，本系统的价值是把搜索、筛选、回应、承接、跟进串起来；不保证流量或报名数量。
